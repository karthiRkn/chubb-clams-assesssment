# Frontend UI/UX Requirements

Role-based Angular frontend for Claimant, Claims Officer, Manager, and Admin.

## Claimant
- Dashboard
- Create Claim
- My Claims
- Information Requests

## Claims Officer
- Claims Queue
- Review Claims
- Approve/Reject/Settle

## Manager
- Assignment Dashboard
- Liability Reports
- Officer Metrics

## Admin
- User Management
- Role Management (staff roles only: a claimant stays a claimant)

## UX
Responsive, accessible, Angular Material based UI.
